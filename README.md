# 싹다클린 AI 비서

숨고 요청서 캡처나 고객 사진을 올리면 AI가 분석해서 숨고에 그대로 붙여넣을 답변과 예상 견적을 만들어 줍니다.
기본은 사장님이 답변을 확인한 뒤 숨고 앱에서 직접 보내는 방식입니다. 첫 화면에서 "켜기"를 누르면 숨고 새 요청을 자동으로 가져오고, 설정의 "숨고 답변 보내는 방식"에서 발송 직전까지 자동으로 써 두거나, 견적까지 자동으로 보내게 할 수 있습니다.

## 켜고 끄는 방법

노트북 바탕화면의 "싹다클린 AI 비서" 아이콘을 두 번 누릅니다.

- 꺼져 있으면 켜지고, 접속 비밀번호를 알려줍니다.
- 켜져 있으면 "화면 열기"와 "끄기" 중에서 고를 수 있습니다.

숨고 비서는 첫 화면 맨 위의 "켜기"·"끄기" 버튼으로 켜고 끕니다. 끄면 숨고 크롬 창도 닫히고 확인과 발송이 모두 멈춥니다. 밖에서 접속하기, 숨고 답변 보내는 방식, 프로그램 끄기는 화면 오른쪽 위 "설정"에 있습니다.

## 쓰는 순서

1. 숨고에서 요청서 화면을 캡처합니다.
2. 휴대폰 브라우저로 접속해 "새 문의"에서 캡처를 올립니다. 1분 안에 분석이 끝납니다.
3. 맨 위 "숨고에 보낼 답변"을 확인하고 필요하면 고친 뒤 "승인하고 복사"를 누릅니다.
4. 숨고 앱 채팅창에 붙여넣어 보냅니다.
5. 고객이 사진이나 답을 보내면 같은 문의의 "고객 답장·추가 사진 등록"에 올립니다. 이전 내용과 합쳐 다시 분석합니다.
6. 견적을 낼 수 있으면 "예상 견적"에서 금액을 고르고 "이 금액으로 답변 만들기"를 누릅니다.

## 숨고 자동 확인

첫 화면에서 "켜기"를 누르면 프로그램이 크롬 창을 하나 띄우고 3분마다 숨고 "받은 요청"을 확인해 새 요청서를 자동으로 등록합니다. 캡처를 올릴 필요가 없습니다.

- 처음 한 번, 그 크롬 창에서 사장님이 직접 숨고에 로그인합니다. 프로그램은 아이디와 비밀번호를 받거나 저장하지 않습니다.
- 그 크롬 창은 닫지 말고 최소화해 두세요. 닫으면 자동 확인이 멈춥니다.
- 받은 요청은 읽기만 하고, 요청서를 열지 않아 숨고의 "안 읽음" 표시가 그대로 남습니다.
- 첫 화면 맨 위에 마지막 확인 시각과, 새 문의가 없거나 문제가 있으면 그 사유가 표시됩니다.
- 숨고 로그인이 풀리면 첫 화면에 "숨고 로그인이 필요합니다"가 표시됩니다.
- 숨고가 프로그램을 통한 접속을 문제 삼으면 계정이 제한될 수 있습니다. 끄려면 설정에서 스위치를 끕니다.

## 숨고 답변 보내는 방식 (선택)

설정에서 세 가지 중 하나를 고릅니다.

- 직접 보내기: 화면에서 승인하고 복사해서 숨고 앱에 붙여넣습니다. (기본)
- 발송 직전까지 자동: 분석이 끝나면 노트북의 숨고 창에 새 탭을 열어 답변과 금액(계산된 경우)을 써 두고 멈춥니다. 캐시가 나가는 "견적 보내기"는 그 탭에서 직접 누릅니다. 금액을 계산할 수 없는 문의는 금액 칸을 비워 둡니다.
- 자동 발송: 분석이 끝나는 대로 사장님 확인 없이 견적을 보냅니다. 아래는 자동 발송에 해당합니다.

- 보낼 때마다 숨고캐시가 나갑니다.
- 견적 금액 칸에는 단가표 기준(없으면 원가 기준)의 최소 금액을 넣고, 설명에는 금액 범위가 들어간 답변을 넣습니다.
- 금액을 계산할 수 없는 문의(청소, 정보 부족)와 업무가 아닌 요청은 보내지 않고 "승인 대기"로 둡니다. 보내지 않은 사유는 문의 목록에 표시됩니다.
- 한 문의에 한 번만 시도합니다. 보내기를 눌렀는데 발송이 확인되지 않으면 더 누르지 않고 멈춥니다.
- 숨고가 프로그램을 통한 발송을 문제 삼으면 계정이 제한될 수 있습니다.

## 카톡 일감 잡기 (선택, 시험 버전)

카카오톡 업무방에 `[방문견적]` 같은 글이 올라오면 바로 답을 보내는 기능입니다. 첫 화면의 "카톡 일감 잡기"에서 켜고 끕니다. 꺼져 있으면 카카오톡을 건드리지 않습니다.

- 설정에서 지켜볼 채팅방 이름, 찾을 말, 보낼 글을 정합니다.
- 켜 둔 동안 1.5초마다 그 방의 마지막 글을 확인하고, 켠 뒤에 올라온 글에만 반응합니다. AI 분석 없이 글자가 들어 있는지만 봅니다.
- 지금은 시험 버전이라 답을 같은 방에 보냅니다. 글 올린 사람에게 개인톡을 보내는 것은 아직 만들지 않았습니다.
- 이 노트북(맥)의 카카오톡이 로그인된 채 켜져 있어야 하고, 시스템 설정의 "손쉬운 사용"에서 프로그램을 실행한 앱을 허용해야 합니다. 윈도우에서는 아직 되지 않습니다.
- 카카오가 자동화 프로그램 사용을 문제 삼으면 계정 이용이 제한될 수 있습니다.

## 견적 계산

금액은 AI가 아니라 정해진 규칙으로 계산하며, 두 가지를 나란히 보여줍니다. 숫자는 `config.json`에서 바꿉니다.

- 단가표 기준: 1톤 차량 35~40만 원 × 대수 + 작업자 15~20만 원 × 인원 + 사다리차(첫 1시간 15만 원, 이후 시간당 10만 원)
- 원가 기준: (고용 인건비 + 폐기물 처리비 + 기름값 + 식대 + 사다리차) ÷ (1 − 이익률). 소형 수거 25~30%, 일반 작업 40%

청소 문의는 아직 원가 기준이 없어 자동 계산하지 않고, 금액을 직접 입력하게 되어 있습니다.

## 밖에서 휴대폰으로 접속하기

같은 와이파이 안에서는 화면에 표시된 "휴대폰" 주소로 바로 접속됩니다.

밖에서는 켤 때 화면에 표시되는 "외부 접속" 주소(https://….trycloudflare.com)로 접속합니다.
- 이 주소는 프로그램을 다시 켤 때마다 바뀝니다. 최신 주소는 `data/public_url.txt`에도 적히고, 카카오톡 알림을 연결했다면 카톡으로도 옵니다.
- 주소를 아는 사람은 누구나 로그인 화면까지 올 수 있습니다. 주소와 접속 비밀번호(숫자 8자리 이상)를 남에게 알려주지 마세요.
- 설정의 "밖에서도 접속하기" 스위치로 켜고 끕니다.

## 카카오톡 알림 (선택)

분석이 끝나면 사장님 카카오톡 "나와의 채팅"으로 요약을 보냅니다.

1. https://developers.kakao.com 에서 애플리케이션을 만듭니다.
2. 카카오 로그인을 켜고, Redirect URI에 `접속주소/kakao/callback`을 등록합니다. (예: `http://localhost:3210/kakao/callback`)
3. 동의항목에서 "카카오톡 메시지 전송"을 켭니다.
4. `.env`의 `KAKAO_REST_KEY`에 REST API 키를, `BASE_URL`에 접속 주소를 넣고 프로그램을 다시 켭니다.
5. 첫 화면 아래 "카카오톡 알림 연결하기"를 눌러 동의합니다.

## 파일

- `prompt.md` — AI에게 주는 업무 규칙과 답변 말투. 답변이 마음에 들지 않으면 여기를 고칩니다.
- `config.json` — 단가, 원가, 이익률
- `data/` — 문의 기록과 사진. 오래된 문의 폴더는 지워도 됩니다.

## 다른 컴퓨터에 설치하기 (개발자용)

윈도우 노트북은 [INSTALL-WINDOWS.md](INSTALL-WINDOWS.md)를 따라 합니다. 아래는 맥 기준입니다.

1. Node 22 이상, Google Chrome, Claude Code(로그인), cloudflared를 설치합니다.
2. 저장소를 내려받고 `npm install`을 실행합니다.
3. `./scripts/install-launcher.sh`로 바탕화면 아이콘을 만듭니다.
4. 처음 켜면 `.env`가 만들어지고 접속 비밀번호가 정해집니다. 문의 기록(`data/`)은 저장소에 포함되지 않습니다.
