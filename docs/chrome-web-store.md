# 크롬 웹스토어에 확장 올리기 (일부 공개)

웹스토어에 올리면 사장님은 링크를 열고 **Chrome에 추가** 한 번만 누르면 설치가 끝나고, 업데이트도 저절로 됩니다. 압축 풀기·개발자 모드·폴더 고르기를 하지 않아도 됩니다.

등록은 구글 계정 로그인과 등록비 결제가 필요해서 사람이 직접 해야 합니다. 아래 순서대로 하고, 칸에 넣을 글은 이 문서에서 복사해 붙여넣으면 됩니다.

준비물(이 저장소에 있음)

| 무엇 | 위치 |
|---|---|
| 올릴 파일(zip) | 비서 사이트에 로그인한 뒤 https://ssakda.sect.kr/api/extension.zip 을 열면 받아집니다. 또는 저장소에서 `cd extension && zip -r -X ../ssakda-extension.zip . -x ".*"` |
| 아이콘 128×128 | `extension/icons/icon128.png` |
| 스크린샷 1280×800 | `docs/store/1-dashboard.png`, `docs/store/2-reply-draft.png`, `docs/store/3-popup.png` |
| 작은 홍보 타일 440×280 | `docs/store/promo-440x280.png` |
| 개인정보 처리방침 주소 | https://ssakda.sect.kr/privacy.html |

## 1. 개발자 등록 (처음 한 번)

1. https://chrome.google.com/webstore/devconsole 에 구글 계정으로 로그인합니다. 오래 쓸 계정으로 하세요. 나중에 업데이트도 이 계정으로 올립니다.
2. 개발자 계약에 동의하고 등록비 5달러를 결제합니다(한 번만).
3. 계정 설정에서 연락용 이메일을 넣고 인증합니다. 인증을 마쳐야 제출할 수 있습니다.

## 2. 새 항목 만들기

1. **새 항목** → 위의 zip 파일을 올립니다.
2. 아래 탭들을 채웁니다.

### 스토어 등록정보 탭

- 설명 (그대로 붙여넣기)

```
숨고(soomgo.com) 고수를 위한 AI 비서입니다. 싹다클린 AI 비서 사이트와 함께 씁니다.

· 비서 사이트에서 "켜기"를 누르면 크롬에 숨고 창이 열립니다. 숨고 로그인은 평소처럼 그 창에서 직접 합니다.
· 1분마다 숨고 채팅 목록을 확인하고, 새 채팅방이 생기면 그 방을 새 탭으로 열어 AI가 첫 응대(확인할 것과 필요한 사진 요청)를 씁니다.
· 정해 둔 방식대로 채팅창에 써 두기만 하거나(사장님이 읽어 보고 전송), 바로 보냅니다.
· 켜기 전에 있던 채팅방, 이미 대화 중인 방, 업무와 관계없는 요청, 연락처나 금액이 들어간 답장은 보내지 않습니다.
· 숨고 아이디와 비밀번호는 읽거나 저장하지 않습니다.

비서 사이트의 접속 비밀번호가 있어야 쓸 수 있습니다.
```

- 카테고리: 생산성(Productivity) 아래의 업무 흐름 관련 항목
- 언어: 한국어
- 아이콘: `extension/icons/icon128.png`
- 스크린샷: `docs/store/` 의 1280×800 세 장
- 작은 홍보 타일: `docs/store/promo-440x280.png`

### 개인정보 보호 탭

- 단일 목적

```
숨고 고수 계정에 새 채팅방이 생기면, 그 채팅방 내용을 바탕으로 AI가 쓴 첫 응대를 채팅창에 써 두거나 보내는 것.
```

- 권한별 사유

| 권한 | 사유 (붙여넣기) |
|---|---|
| tabs | 숨고 채팅 목록 창을 열어 두고, 새 채팅방을 새 탭으로 열어 읽고 답장을 써 넣기 위해 씁니다. |
| alarms | 1분마다 숨고에 새 채팅방이 생겼는지 확인하기 위해 씁니다. |
| storage | 확장의 지금 상태와 비서 서버 주소를 기억하기 위해 씁니다. |
| 호스트 권한 soomgo.com, *.soomgo.com | 숨고 채팅 목록과 채팅방을 읽고, 고객이 올린 사진을 받고, 채팅창에 답장을 써 넣기 위해 씁니다. |
| 호스트 권한 ssakda.sect.kr | 사용자의 싹다클린 AI 비서 서버와 채팅방 내용·답장·상태를 주고받기 위해 씁니다. |

- 원격 코드 사용: **아니요** (확장 안의 파일만 씁니다)
- 데이터 사용: **개인 통신**(채팅 내용)과 **웹사이트 콘텐츠**(채팅방 글·사진)를 체크합니다. 그리고 아래 세 가지 약속에 모두 체크합니다.
  - 승인된 사용 사례 외에 제3자에게 판매하거나 넘기지 않음
  - 단일 목적과 관계없는 용도로 쓰지 않음
  - 신용도 판단이나 대출 목적으로 쓰지 않음
- 개인정보처리방침 URL: `https://ssakda.sect.kr/privacy.html`

### 배포 탭

- 공개 범위: **일부 공개(Unlisted)** — 링크를 아는 사람만 설치할 수 있고 검색에는 나오지 않습니다.
- 지역: 대한민국(또는 모든 지역)

### 검토자에게 남길 말 (테스트 안내 칸이 있으면)

```
이 확장은 사용자의 비공개 서버(ssakda.sect.kr)와 숨고 고수 계정이 있어야 동작합니다.
서버는 접속 비밀번호로 보호되어 있고, 숨고 채팅방이 있는 고수 계정이 필요합니다.
확장은 숨고 채팅 화면과 위 서버 밖의 사이트는 읽지 않고, 원격 코드를 쓰지 않습니다.
```

검토자가 직접 돌려 봐야 한다고 하면, 검토용 접속 비밀번호를 따로 만들지 함께 정합니다. 지금 비밀번호는 고정이라 그대로 알려 주면 안 됩니다.

## 3. 제출과 승인

1. **검토를 위해 제출**을 누릅니다. 보통 며칠 걸리고, 고칠 것이 있으면 메일이 옵니다.
2. 승인되면 항목 페이지의 스토어 주소(`https://chromewebstore.google.com/detail/...`)를 복사합니다.
3. 서버 `.env`에 한 줄을 넣고 비서를 다시 켭니다. 그러면 비서 사이트의 안내 페이지가 "크롬 웹스토어에서 확장 추가하기" 버튼 하나로 바뀝니다.

```
ssh infraserver
nano ~/apps/ssakda/.env      # 맨 아래에 EXT_STORE_URL=복사한 주소 를 넣고 저장
sudo -n /bin/launchctl kickstart -k system/cloud.ssakda.server
```

4. 사장님 PC에 파일로 설치한 확장이 있으면 `chrome://extensions` 에서 삭제한 뒤 웹스토어에서 설치합니다. 둘 다 켜 두면 숨고 창이 두 개 뜹니다.

## 4. 확장을 고쳤을 때 (업데이트)

1. `extension/manifest.json`의 `version`을 올립니다(예: 0.1.2 → 0.1.3). 비서 사이트는 이 번호로 옛 버전을 알아봅니다.
2. 커밋·배포한 뒤, 새 zip을 받아 개발자 대시보드의 **패키지** → **새 패키지 업로드** → **검토를 위해 제출**을 누릅니다.
3. 승인되면 사장님 크롬에 저절로 업데이트됩니다.
